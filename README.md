# Phidias Samples

This repository contains a collection of examples and projects demonstrating how to use **PHIDIAS** (PytHon Interactive Declarative Intelligent Agent System). PHIDIAS is a Python framework that seamlessly integrates logic-based and declarative programming within standard Python code. It is designed to build Multi-Agent Systems (MAS) and intelligent IoT devices using the **Belief-Desire-Intention (BDI)** paradigm.

## Getting Started

The following instructions will help you set up your environment to successfully run the examples provided in this repository.

### Prerequisites

To run these samples, you need to have Python installed on your machine, along with the core PHIDIAS library.

- **Python 3.7** or higher
- **pip** (Python package installer)

### Installation & Setup

1. **Clone this repository:**
   First, download the samples to your local machine.
   ```bash
   git clone [https://github.com/Giovannicampo/phidias_samples.git](https://github.com/Giovannicampo/phidias_samples.git)
   cd phidias_samples
   ```

2. **Install the PHIDIAS framework**
   You must install the core PHIDIAS engine to execute the declarative code. You can install it directly via pip:
   ```bash
   pip install phidias
   ```
   Alternative installation (from the official source code):
   If you prefer to install it from the main repository, you can clone it and install it manually:
   ```bash
   git clone [https://github.com/corradosantoro/phidias.git](https://github.com/corradosantoro/phidias.git)
   cd phidias
   pip install .
   ```

3. **Run the demo**
   ```bash
   python demo.py
   ```
